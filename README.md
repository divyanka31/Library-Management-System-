# Library Management System

## About the Project
A basic Library Management System developed using Python. It helps manage books, library members, and book issue/return transactions.

## Features
- Manage book records
- Manage library members
- Record book issue and return transactions
- Store data using plain text files
- Use Python functions, lists, dictionaries, and file handling

## Technologies Used
- Python
- VS Code
- Text file storage

## Project Files
- `LibManSys.py` – Main Python program
- `books.txt` – Book records
- `members.txt` – Member records
- `transactions.txt` – Transaction records

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

   `python3 LibManSys.py`

## Learning Objectives
This project demonstrates basic Python programming, functions, data structures, and file handling.
